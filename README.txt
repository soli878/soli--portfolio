SELOME PORTFOLIO — QUICK START

1. Extract this folder.
2. Add your own portrait to images/ and name it selome.jpg.
3. Open index.html in your browser, or open the folder in VS Code.
4. Recommended: install the VS Code extension "Live Server", right-click index.html, and choose "Open with Live Server".
5. Update the placeholder email address (your.email@example.com) in index.html.
6. Review every achievement/project description and change anything that is inaccurate or outdated before publishing.

This is a front-end template only. Contact buttons use an email link; there is no database or server-side form.
